# Word-Scramble

Windows Forms app which allows user to play the game and enjoy unscrambling words – the "Word Scramble" game.

## Project goals:

Create an interactive and enjoyable word scramble game using C# and Visual Studio.
Develop a project that demonstrates programming fundamentals such as loops, conditionals, arrays/lists, and string manipulation.

## Problem the Project Solves:

Many simple educational games online are either repetitive, cluttered with ads, or not designed for beginners learning programming concepts. This project provides a lightweight and engaging word scramble game that helps users improve vocabulary, spelling, and critical thinking skills while also serving as a practical example of C# game development.

## IndexForm
The ```IndexForm``` class represents the main form of the Word Scramble. It provides the following functionalities:
- Scrambled word puzzles for players to solve.

- Keeping track of successful guesses, failed attempts, and the number of guessed words.

- Random word selection from a list of words in a text file.

- Automatic word regeneration after a set number of failed attempts.
